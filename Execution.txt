============================================================
EXECUTION GUIDE
Movie Ticket Booking System
============================================================

1. Open MySQL Workbench or MySQL CLI.

2. Create the database:

   CREATE DATABASE movie_booking_db;

3. Restore the complete database dump.

   From Command Prompt, run:

   mysql -u root -p movie_booking_db < movie_booking.sql

   On Windows, if mysql is not recognized, use the full path:

   "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p movie_booking_db < movie_booking.sql

   Enter your MySQL password when prompted.

   Note: The database dump contains the table definitions, data, and relationships required for restoration.

4. Verify the database:

   USE movie_booking_db;
   SHOW TABLES;

5. Verify the records:

   SELECT COUNT(*) FROM customers;
   SELECT COUNT(*) FROM movies;
   SELECT COUNT(*) FROM theatres;
   SELECT COUNT(*) FROM bookings;

6. Run the query files in order:

   Simple_queries.txt
   Medium_queries.txt
   Hard_queries.txt

7. Recommended learning order:

   Simple
      ↓
   Medium
      ↓
   Hard

IMPORTANT
============================================================

Database:
movie_booking_db

Tables:
customers
movies
theatres
bookings

Relationships:
bookings.customer_id → customers.customer_id
bookings.movie_id    → movies.movie_id
bookings.theatre_id  → theatres.theatre_id

The file movie_booking.sql is the recommended method for restoring the database.

Database_Creation_Insertion.txt may be used as an alternative only if it contains the required executable SQL statements.
